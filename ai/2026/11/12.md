## 不再围绕任务进化！The Trinity提出能力驱动的多模态RSI新范式

> **分类：** 技术前沿解读
> **来源：** [机器之心](https://mp.weixin.qq.com/s?__biz=MzA3MzI4MjgzMw==&mid=2651073845&idx=3&sn=8b92de9dc32524d0bfcb028f1c118644&chksm=857f5db3768aa5fce5fc146d76d689964e6c80022e62a0bb6bbd57685970417f5f81cc0933e6&scene=126&sessionid=1794442331#rd)

**核心洞察：** The Trinity 的提出标志着递归自我改进（RSI）从任务驱动转向能力驱动的新范式。通过将任务分解为共享的能力需求，并围绕这些能力构建训练环境和演化 Harness，该框架有效缓解了任务级优化带来的过拟合和 reward hacking 风险。这种能力驱动的组织方式，不仅促进了跨任务的经验共享和能力积累，还为未来的能力树与 Harness 的共同演化提供了可能。这一范式的成功，可能为多模态智能体的长期发展提供新的思路和方法。
**内容简介：**

- 技术路径：提出全模态全任务递归自我改进框架 The Trinity，通过能力驱动的方式实现跨任务、跨模态的持续演化。
- 能力树：将任务分类为 Task Tree，依据能力需求转换为 Capability Tree，并沿着 Capability Tree 进行演化。
- 实验结果：经过四轮 RSI，在 28 个训练基准和 18 个未见基准上的平均得分分别提升 34.1 分和 26.2 分，并展现了向真实机器人任务迁移的潜力。
- 协同进化：通过 Agent–Environment Co-evolution，让环境根据智能体的表现生成和调整训练挑战，减少对人工构建环境和迭代 Harness 的依赖。
- 共享能力：不同任务可能需要相同的底层能力，通过围绕共同需求组织经验，实现跨任务的能力共享和迁移。
- 实验分析：验证了按能力组织经验和针对共同能力生成训练环境的有效性，并探讨了 Capability Tree 的自定义与动态调整。

## HyperAgent：openJiuwen 对未来 Agent 架构的思考与实践

> **分类：** 技术前沿解读
> **来源：** [机器之心](https://mp.weixin.qq.com/s?__biz=MzA3MzI4MjgzMw==&mid=2651073583&idx=2&sn=b51e6ed1e5957fa9dffb517b737cd2c1&chksm=855416cb751504507067f74d5f897ff163d43c7ab28a679cc8ade09d0eb786686e6494bdeaa5&scene=126&sessionid=1794442331#rd)

**核心洞察：** openJiuwen 的 HyperAgent 架构和 AgentOS 设计，标志着 AI Agent 从单次任务执行向持续工作、自我演进和多主体协作的转变。其核心在于将「智能主体」的需求与「工程应用」的需求融合在一起，通过事件驱动架构、Persistent Agent、CoRSI 和 Swarm 引擎等机制，实现了主动性、永续性、成长性和协作性。同时，通过分布式运行时、可控插件机制、增强操控能力和算力亲和优化，满足了真实业务环境中的确定性、扩展性、开放性和经济性要求。这一设计不仅为未来 Agent 的发展提供了技术路径，也为企业在关键业务中应用 Agent 提供了可靠的基础设施支持。
**内容简介：**

- 架构与定义：openJiuwen 提出 HyperAgent 架构，并详细解释了 Agent 的「二元属性」，即既是软件程序也是智能主体。
- 八项特征：HyperAgent 应具备主动性、永续性、成长性、协作性、确定性、扩展性、开放性和经济性。
- AgentOS 架构：openJiuwen 提出 AgentOS 分层设计，支撑 HyperAgent 的开发、运行、协作与演进，包含六层架构和两项贯穿能力。
- 实现与部署：HyperAgent 被建模为「元 Agent-App」，支持多客户端、多 Channel 和内部协作，并提供前端与 Agent Serving 的部署方式。
- 智能主体需求：AgentOS 设计支持主动性、永续性、成长性和协作性，通过 EDA 架构、Persistent Agent、CoRSI 和 Swarm 引擎实现。
- 应用属性需求：AgentOS 设计支持确定性、扩展性、开放性和经济性，通过分布式运行时、可控插件机制、增强操控能力和算力亲和优化实现。
- 部署方式：openJiuwen 提供个人桌面和企业分布式两种部署方式，支持日常编码、办公和多人协作、多业务应用的场景。
- 结语：openJiuwen 把 Agent 当作需要长期运行、持续成长的「数字主体」，AgentOS 架构统一考虑了智能主体和工程应用需求。
