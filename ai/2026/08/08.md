## 《BigBang-V1》发布：RSI原生训练35B模型，AI自主造题与自我迭代，100%合成数据跑赢万亿参数模型

> **分类：** 产品与商业模式
> **来源：** [量子位](http://mp.weixin.qq.com/s?__biz=MzIzNjc1NzUzMw==&mid=2247910686&idx=1&sn=9bef81c8afd2dd38ccb60f298bad3673&chksm=e9e20c16e4b0e4caef2699966188594299a78096513c93089e388509e6891f11ff07c633e06d&scene=126&sessionid=1786147987#rd) 、 [机器之心](http://mp.weixin.qq.com/s?__biz=MzA3MzI4MjgzMw==&mid=2651049091&idx=1&sn=0c09a4da15d0bbc17788c0b5a5e6e364&chksm=85049ff44c361078a983d4738e18788d8174a673f747c91b56807300906c84994974edf9b2ba&scene=126&sessionid=1786148000#rd)

**核心洞察：** 《BigBang-V1》的价值不在于“小模型战胜大模型”的叙事，而在于把后训练阶段的核心优化对象从“模型参数”转向“数据生产系统”本身。当数据边际收益递减、人类出题能力难以跟上模型进化时，竞争正从“用更多数据训练模型”演变为“让AI更快地设计出值得训练的新任务”。其工程关键是以“可验证性”为基石：用工具执行替代模型自评来保证训练信号，再用外层真实任务评测校准内层Critic的误判，避免合成数据坍缩。对从业者而言，这提示合成数据不是一次性产物，而应被设计为可迭代、可被环境反馈校正的“课程引擎”；同时，模型能力向搜索、代码等领域的迁移证实了“过程性能力”比“知识记忆”更具通用性。任何具备客观验证信号的高价值领域（数学、代码、科学实验）都可能复制“AI出题-解题-验证-反馈”的数据飞轮，未来大模型竞争的关键变量将从算力堆叠转向数据生产系统的智能化程度。
**内容简介：**

- 事件发布与技术路线：无尽前沿团队（依托上海交大、深势科技）发布《BigBang-V1》，定位为首个基于递归自我改进（RSI）原生方式训练的基座模型，参数规模35B、激活约3B，支持262K长上下文，后训练数据100%由AI自主合成，聚焦科学前沿任务。
- 核心机制与数据飞轮：构建Generator-Critic内层循环与真实任务评测外层循环，AI不仅能自主生成题目与答案，还可修改数据生产程序、检查结果，并根据模型实际能力变化调整下一轮合成策略，用约1万条合成数据实现跨规模性能突破，形成数据层面自我进化闭环。
- 性能表现：在10/11项评测上超过基础模型，拿下35B模型在长程搜索、代码、科研等类别中的10项第一，并在FrontierScience Research（46.2分）、Humanity's Last Exam（50.3分）等四项基准上超越1.6T参数的DeepSeek V4 Pro Preview；实测展示转座子定位精确到断点4144431、论文复现评分0.7657等可追溯多步推理能力。
- 能力迁移与通用性：以科研任务为核心，但能力显著迁移至BrowseComp 76.5、SWE-Bench Pro 54.2等长程检索与软件工程场景，表明模型学到的是跨领域问题解决流程（搜索证据、调用工具、验证结果、调整路线），而非单一任务记忆。
- 开源生态与安全边界：模型与技术报告已同步开源，瞄准AI for Science与开放式通用智能；人类仍负责定义研发目标、风险边界与验收标准，AI不能自行修改评测标准，对抗与验证链确保合成数据不坍缩。

## Rust 采纳 LLM 贡献政策：AI 代码需过更高门槛，人类判断与责任不可外包

> **分类：** 深度行业分析
> **来源：** [机器之心](http://mp.weixin.qq.com/s?__biz=MzA3MzI4MjgzMw==&mid=2651049091&idx=2&sn=fa441a00441dd5f3d222e6169435d14f&chksm=857e6e525532b2530fa82b867ee7063f7cf4eab3f423657566e499cb5051f86fdb29c6a57376&scene=126&sessionid=1786148000#rd)

**核心洞察：** Rust 的 LLM 政策本质上是为「AI 规模化生产代码」时代提前制定治理协议。它揭示了一个关键拐点：当代码生成成本趋近于零，软件工程的瓶颈不再是「写代码」，而是「做决策」——理解需求、权衡设计、确认责任、承担长期维护风险。政策的精妙之处在于它没有对抗 AI，而是将人类不可替代的部分（理解、判断、责任）明确划出边界，同时用「披露+更高门槛」机制将信任成本显性化。对 Coding Agent 产品而言，这预示着新的差异化方向：不是比拼 PR 数量，而是比拼如何系统性降低 Reviewer 的认知负担，例如提供决策依据、自动验证影响面、控制任务边界。开源社区与企业的治理框架，将成为 AI 编程规模化落地的下一个战场。
**内容简介：**

- 现象与痛点：rust-lang/rust 仓库积压 1300 个未关闭 PR，AI 让「高质量 PR」信号失效，维护者审核负担骤增。
- LLM 可快速生成格式工整、测试齐全的代码，但作者未必理解设计，甚至无人类参与。
- 代码成本降低，人工审核成本成为新瓶颈。
- 政策核心：Rust 五团队采用 LLM 使用政策，不搞一刀切，而是区分「辅助」与「直接生成」。
- 允许 LLM 用于回答问题、分析、检查、翻译、总结、辅助 Review 等；个人私下使用无需披露。
- 公开提交 LLM 生成内容必须披露；AI 直接生成代码需满足事先安排、非关键、高质量、测试充分且经充分审查。
- 涉及 soundness 关键改动，除非作者是相关领域专家，否则禁止 LLM 生成；即便如此也强烈不建议。
- 执行机制：维护者无义务审核 AI 生成 PR，违反政策可关闭；同时禁止仅凭代码风格指责作者，疑似隐瞒交由 Moderation 团队处理。
- 行业启示：AI 编程竞争正从「生成更快」转向「降低人类审核负担」；未来 Coding Agent 的价值将体现在自动测试、解释设计决策、控制任务范围、主动降低 Reviewer 认知负担等方面。

## 具身基础模型「DM0.5」发布：开源可复现、全科评测登顶，以数量级推理加速推进规模化落地

> **分类：** 产品与商业模式
> **来源：** [机器之心](http://mp.weixin.qq.com/s?__biz=MzA3MzI4MjgzMw==&mid=2651048992&idx=1&sn=9ecb5c49423b3340c86eb3cf0ddde3ae&chksm=855701bfa07d48cad20f06b283f16f5e1f95f3f1751330faea53bfd721ad34f3bf7e60bd5ab9&scene=126&sessionid=1786148000#rd)

**核心洞察：** 「DM0.5」的发布揭示了具身智能竞争正从「Demo 演示」转向「可复制的基础设施」。其战略意图并非依靠单一参数规模或榜单分数取胜，而是以「开源 + 消费级显卡可微调 + 数量级推理加速」的组合，将开发者生态视为长期壁垒。核心工程取舍在于：在 4B 参数量级上，通过多源数据（真机+视频+场景重建）与面向真实任务的架构设计（时序记忆、轨迹对齐），逼近更大模型的专项性能，从而把「可用性」前置到模型底座阶段。对从业者而言，可复用的信号是：具身模型竞争焦点正从「算法创新」迁移至「数据工程 + 部署体验 + 生态共建」的综合能力；未来能在多本体、长程任务和低算力环境下稳定泛化的开放模型，将更容易获得开发者数据飞轮。同时需警惕：真机评测成功率仍不足一半，规模化落地还需在安全控制、故障恢复与合规方面建立更明确的评估标准。
**内容简介：**

- 产品定位：原力灵机发布具身基础模型「DM0.5」，定位为开发者可长期依赖的规模化落地底座，而非单点 Demo 展示。
- 数据与架构：基于 4B 参数与 15 万小时多源数据（5 万小时真机操作、10 万小时 Egocentric 视频、100 万平米场景重建），引入上下文抽象层（60s 时序记忆）、具身思维链与轨迹对齐层。
- 关键指标：单张 4090 上 18 小时完成微调，成本降 60%；Zero-shot 提升 31%、Few-shot 提升 45%、Fine-tuning 提升 20%；单卡推理延迟 534ms→57.49ms（9.29x），API p50 67.75ms。
- 评测表现：LIBERO 综合 99.0%，刷新 RoboTwin 2.0、R2R 等榜单；RoboChallenge Table30 V2 真机评测以 43% 成功率、54.42 分登顶，覆盖 ARX5、UR5、ALOHA、Dexmal-Mirror 四种平台。
- 开源生态：全面开源模型权重与文档，向 LeRobot 贡献核心代码，并开放 SO101 LoRA SFT 工作流，降低开发者复现与二次开发门槛。

## 「字节Seed」确立反蒸馏原则：张一鸣为何坚持自研路径而非抄近道

> **分类：** 市场动态
> **来源：** [36氪](http://mp.weixin.qq.com/s?__biz=MzI2NDk5NzA0Mw==&mid=2248898326&idx=4&sn=aa8c3adb1751dc3da4a3668532ce1be8&chksm=e88806dca9e381e75a1d1b91fdd195fc3e78592e126fc3d3218ca2dfd10d62c61ec9f3cdacaf&scene=126&sessionid=1786147964#rd)

**核心洞察：** 「字节Seed」放弃蒸馏并非技术保守，而是对「AI实验室核心竞争力」本质的清醒认知：模型可以通过蒸馏快速进入前沿，但实验室无法通过蒸馏成为前沿。在算力受限、追赶压力巨大的现实下，选择独立探索意味着主动承担短期落后与高昂试错成本，这实际上是在押注下一代智能范式的定义权。对从业者而言，这一决策的价值在于划清了「用别人的数据加速」与「建立自己的数据-能力飞轮」的界线——前者解决benchmark，后者解决未知问题。当行业普遍追求「弯道超车」时，字节用组织意志对抗路径依赖，或将为其在AGI长跑中积累不可替代的原创积累。
**内容简介：**

- 核心决策：字节跳动创始人张一鸣在Seed全员会上明确禁止蒸馏任何外部模型，包括闭源与开放权重模型（如Kimi K3），并出台内部政策，通过API技术检测追溯疑似蒸馏行为。
- 背景与动机：该决策主要源于对「追求真实智能天花板」的长期主义判断，而非TikTok合规压力；内部认为蒸馏虽能短期补齐能力，但无法揭示能力产生的机理，也无助于前沿探索。
- 三次路线争论：2025年初DeepSeek-R1发布后，团队曾提议用美国SOTA模型输出提升推理能力；Blackwell GPU出口管制扩大算力差距时，再次出现「以数据换算力」的呼吁；Kimi K3进入全球第一梯队后，蒸馏动议获得更多支持，最终被张一鸣一锤定音。
- 技术路线选择：Seed选择研究对手论文、重审数据/架构/训练方法，并接受短期落后，以独立探索为代价换取长期竞争力。
- 行业影响：在AI竞争日益依赖蒸馏的背景下，字节的立场为行业提供了一种「反共识」样本，凸显自研基础研究与工程取舍的战略价值。

- 能力与成本：Astra在数学与理论计算机科学上取得突破，10个开放问题中部分解决，仅耗约2000美元Token；但合规与安全投入带来研发减速、权限收紧与潜在发布变化。
- 行业启示：前沿AI竞争衡量标准从模型分数扩展到隔离环境、行动监控、中断机制与事故响应速度。
