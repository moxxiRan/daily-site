## Raven V0.2.0：多 Agent 协作与 Harness 自改进的新范式

> **分类：** 技术前沿解读
> **来源：** [机器之心](https://mp.weixin.qq.com/s?__biz=MzA3MzI4MjgzMw==&mid=2651059900&idx=1&sn=05bd259deaecb05d969bfba6c890ed75&chksm=85a0ecd9c83375f721838caac017125967d3b2b9664fd1eb28f9fa6788eacd970867442641b0&scene=126&sessionid=1790554331#rd)

**核心洞察：** Raven V0.2.0 的发布标志着 AI 系统从单一模型能力向整体 Agent 协作与自我改进迈出了关键一步。其核心设计理念是将递归自我改进（RSI）从模型参数层延伸到 Harness 层，通过模块化的 Harness 框架实现 AI 对自身工作方式的持续优化。这种设计不仅提升了单次任务的执行效果，更重要的是形成了可复用的工作方法，为长期积累与持续成长奠定了基础。Raven 的成功在于其能够在复杂任务中有效组织多 Agent 协作，并通过 Harness 自改进机制实现任务与经验的无缝衔接，为未来 AI 系统的发展提供了新的范式。
**内容简介：**

- 核心设计：Raven V0.2.0 提供了两个核心设计：为递归自我改进（RSI）而设计的 Harness 框架，以及统一编排专业 Agent 的 The Harness of Harnesses。
- 多 Agent 编排：Raven 将自身深度优化的四个子 Agent 与专业 Agent 统一编排，负责成员选择、任务拆解、依赖调度与结果交接。
- Harness 自改进：Raven 的 Harness 从设计上就是可以被 AI 改写的，运行时的 Curator 作为实验性功能开源，跑通了从反馈、生成代码到校验安装的闭环。
- 实际应用：Raven 自身的发布及其在复杂任务中的应用展示了多 Agent 协作与 Harness 自改进的实际效果。
- 评测与性能：Raven 在多 Agent 编排、研究、编码、设计与持续执行等方面的评测结果优于同底座模型下的对比模型。
