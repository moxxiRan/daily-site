## 如何让 Super-agent 成为同事：LobeHub 的组织实验

> **分类：** 产品与商业模式
> **来源：** [赛博禅心](https://mp.weixin.qq.com/s?__biz=MzkzNDQxOTU2MQ==&mid=2247522189&idx=1&sn=59314956d4dbc89258930115e4aa31ce&chksm=c33bf27b9ef880744736bade017731364677d799d451ecf476abe1a46ffe701f2ad7b179ab18&scene=126&sessionid=1793578265#rd)

**核心洞察：** LobeHub 的组织实验展示了如何通过 Agent 的引入和优化，逐步实现从人机协作到完全自动化的组织演进。其核心在于通过 Agent 自动化处理执行、决策和盲区类任务，提升团队协作效率。LobeHub 的三层汇报机制和 Agent Vent 等自我优化手段，使得组织能够不断迭代和提升。这种组织模式不仅提高了工作效率，还为未来完全自动化的组织架构奠定了基础。
**内容简介：**

- 背景介绍：LobeHub 是一款知名的 Agent 工具，拿了两个非常头部机构的投资，并在 DeepSeek v3.2 发布时用 LobeChat 作为工具调用的演示。
- 团队协作卡点：尽管 Agent 提升了每个任务的执行速度，但任务之间的沟通成本没有降低，主要体现在交接上。
- 三类时间黑洞：LobeHub 将团队协作中的时间黑洞分为执行类、决策类和盲区类，并通过 Agent 的自动化处理来提升效率。
- Agent 的职责与在线状态：Agent 需要在其职责边界内主动完成任务，并且要始终在线，以确保任务的稳定执行。
- 架构设计：LobeHub 将 Agent 的循环、会话状态和执行环境拆开来放，以适应长时间任务的执行需求。
- 不同于 DeepSeek 的两点：LobeHub 每个 Agent 都有自己的岗位和职责，并且引入了三层汇报机制来过滤信息和派活。
- 验收瓶颈：随着 Agent 工作速度的提升，人工验收成为新的瓶颈，LobeHub 通过开源的 Acceptance 工具来提升验收效率。
- 组织自我优化：LobeHub 通过 Agent Vent 和自动化巡检来不断优化组织结构和流程。
- 自动驾驶分级：LobeHub 将 AI 组织的演进分为五个级别，从问答工具到自演进组织，逐步减少人类在执行中的角色。

## 复旦创智OpenMOSS团队：混合架构在长上下文任务中的优势与设计策略

> **分类：** 产品与商业模式
> **来源：** [机器之心](https://mp.weixin.qq.com/s?__biz=MzA3MzI4MjgzMw==&mid=2651071440&idx=3&sn=ac0f863b4725bef4e45e4453d7e081e3&chksm=85db2346e893fb853322fbb81b3a2ab33d57ce780dc8ac3b3e9c058e168526e584cd1cb27015&scene=126&sessionid=1793578396#rd)

**核心洞察：** 复旦创智OpenMOSS团队的研究揭示了混合架构在长上下文任务中的独特优势，并提出了一系列有效的设计策略。通过系统比较不同注意力模块的混合效果，研究团队发现，混合位置的协同机制是关键，不同注意力模块在长文训练和长度外推中各有所长。这一发现不仅为当前大语言模型的设计提供了新的思路，也为未来在后训练和多模态训练阶段的混合架构研究奠定了基础。该研究表明，混合架构的核心在于功能互补，而非单一模块的优势，这为长上下文大语言模型的发展提供了新的方向。
**内容简介：**

- 背景介绍：长上下文是大语言模型的重要能力，但计算和显存开销随序列长度显著增长，因此混合架构成为主流。
- 研究观察：论文在376M、776M、1B和3B规模上进行实验，比较了基于RoPE/NoPE全注意力、滑窗注意力（SWA）和门控线性注意力的混合架构在长上下文任务中的表现。
- 核心发现：混合位置（NoPE与带位置偏置注意力的混合）在长文训练和长度外推中更有效；滑窗混合在长度外推中表现优异，但在扩长训练中不如线性混合；线性混合在扩长训练中表现优异，但在长度外推中不如滑窗混合。
- 改进策略：通过增大滑窗窗口和结合LongCE损失，显著提升滑窗混合模型的长文续训表现；提出滑窗线性注意力（SWLA）策略，显著改善线性混合的长度外推。
- 结论总结：混合架构的优势来自不同注意力模块之间的功能互补，未来将探索后训练阶段和多模态训练阶段的表现。
